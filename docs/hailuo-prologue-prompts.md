# Hailuo AI：梦幻玻璃花园序章

## 素材对应

- 第一段首帧：`keyframe-a.png`
- 第一段尾帧 / 第二段首帧：`keyframe-b.png`
- 第二段尾帧：`keyframe-c.png`
- 输出：16:9、6 秒、无字幕、无配乐优先。

## 第一段（A → B）

单一连续电影镜头。摄影机从彩色玻璃花园入口以稳定、缓慢的低位推轨向前，跟随画面中唯一一只棱镜蝴蝶。蝴蝶沿湿润马赛克小径飞行，翅膀保持相同的翡翠绿、湖蓝、珊瑚橙和琥珀金透明纹理。阳光穿过彩色玻璃和叶片，在地面产生会自然移动的虹彩焦散；近景叶片经过镜头形成真实视差，空气里只有少量浮尘。镜头持续前进，无切镜、无突然变焦。最后一秒蝴蝶从左下向右上靠近镜头，其中一片半透明翅膀覆盖大部分画面，形成折射遮挡，并严格停在所给尾帧构图。

限制：建筑结构、玻璃柱、道路和植物位置必须稳定；只出现一只蝴蝶；不要人物、文字、标志、额外门窗、物体融化、植物变形、蝴蝶增殖、镜头跳切、卡通或插画风格。

## 第二段（B → C）

从第一段完全相同的棱镜蝴蝶翅膀遮挡中连续开始。摄影机穿过彩色折射，蝴蝶重新飞离镜头并沿中央玻璃长廊引导摄影机前进。保持相同温室建筑、湿润马赛克地面、青绿植物、珊瑚花、金色晨光和彩色玻璃焦散。摄影机以平滑稳定的电影推轨逐渐抬高，最终正对温室尽头的暖胡桃木双开门。蝴蝶减速并悬停在右侧古铜门把手旁。最后半秒镜头完全稳定，不再推进，严格停在所给尾帧构图，为网页无缝接管画面。

限制：保持蝴蝶外观、门的形状、把手位置和建筑结构稳定；只出现一扇目标双开门和一只蝴蝶；不要人物、文字、标志、突然切镜、物体融化、门自动打开、额外蝴蝶、卡通或插画风格。
