# 立体物件与拿起查看

用户补充要求：物品尽量使用真实 3D，不以贴图平面冒充实体；即使没有关联记录，也可点击拿起并旋转观察。

- 茶杯、书本、花盆、灯具、键盘、鼠标使用真实网格建模。轮廓、厚度、孔洞、内部和背面由几何体表达，不使用面向相机的物件图片。
- 茶杯有内外壁、杯底、杯沿和环形把手，能够从上方与背面查看；材质用于陶瓷、金属、木头等表面表现，不替代结构。
- 照片、用户上传图片和电脑显示内容属于真实图文内容，保留图像或原生 UI，不作为家具实体的替代。
- 新增可复用物件检查模式：点击可拿起小物件 → 从原位置隐藏，呈现同一模型的近景 → 鼠标或触摸拖动旋转，滚轮调整观察距离 → “放回”或 Esc 退出并恢复原位。
- 检查期间停用房间镜头操作；旋转不会触发点选；不改动物件的持久摆放位置。电脑的软件模式与拿起模式互斥。
- 书桌样板先验证茶杯、书本、花盆和鼠标的立体检查。较大固定家具不提供不合理的整件拿起，可使用近景查看或原有专属交互。
- 物件展示与检查复用相同建模代码及材质，避免只在近景做出模型。电脑软件、猫咪、开灯等已有专属交互保持不变。
- 验收：茶杯内腔与把手孔洞真实可见，旋转一周无纸片侧面；退出后原位置恢复，无残留或重复模型；触屏可旋转，Esc 有效。

本文件优先于早期计划中可能将家具或物件制作为图片素材的建议。
